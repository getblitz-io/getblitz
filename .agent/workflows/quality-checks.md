// turbo-all

1. Validate types using `pnpm typecheck`
2. Run standard linting via `pnpm lint`
3. Verify formatting via `pnpm format`
4. Run tests with `pnpm test`
5. If there are violations, use `pnpm lint:fix` and `pnpm format:fix` to automatically correct them where possible.
